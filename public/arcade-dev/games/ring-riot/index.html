2 PHONES: Player 1 creates a room and shares the six-character code. Player 2 selects a wrestler and joins from another phone.

STRIKE: tap for a quick jab; hold until “heavy punch,” then release. The thin blue bar shows when you can act again.

GRAB: catch them, then choose a slam. Hold for a stronger grapple. RUN from a grapple throws them into the ropes.

DEFEND: BLOCK beats strikes. EVADE beats grabs. Time either just before impact to reverse.

RUN / CORNER: tap RUN to start or stop; steer with the joystick. STRIKE while running hits harder. Walk toward a corner and tap RUN to climb; STRIKE dives, EVADE climbs down.

DOWN: tap actions to recover faster. Hold RUN to play dead. Once ready, release RUN to rise—or STRIKE / GRAB to surprise someone close. Hold BLOCK while rising to crouch, then STRIKE low, GRAB, or EVADE-roll.

KEYBOARD: WASD/arrows move · J/B strike · K grab · L evade · I/R block · X/Shift run · Esc pause.
